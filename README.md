# InferzeroTheMuddWay
This is my own customized version of the project "Inferzero" made by https://github.com/rizagp.

Minor changes including art style and introduction of EXE instead of .CMD. No changes to the kernels. This build is meant for Windows only. Please see the creators releases page for a Linux build https://github.com/rizagp/inferzero/releases.

Self-hosted AI was used to help automate the changes. For more information, please go to https://github.com/rizagp/inferzero/releases.

This is currently built on version 2026.11.24.02.
