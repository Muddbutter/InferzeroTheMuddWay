Measured results, setup by setup

Every number below was measured on a real machine, most of them by the people who own it, and posted on GitHub with its log. Each table is one setup: its GPU (or GPUs), the system it ran on, and the models tried there.

Prompt
prompt processing (pp): how fast a prompt is read, in tokens a second, at the prompt length shown.
Generation
token generation (tg): how fast the answer is written, in tokens a second; one token is about three quarters of a word.
With drafting
generation with the model's draft head (MTP, DFlash2 or Gemma's drafter), which gives exactly the same text.

Models are Qwen3.8 27B GSQ-RCO IQ3_S unless named; the others are the files the launcher downloads. Numbers move with each release, so every row says which one. Setups we have not measured are the most useful thing you can add: how to measure yours. Qwen3.8 Flash Next's numbers are its fast mode's (--fast): since 2026-11-22 its default is the precise mode, closer to the full-precision model on code and tables (KL against f32 0.0415 -> 0.0033 on markdown), whose prompts run at about 60 % of the fast mode's speed (the laptop, 3,584 tokens: 74.8 against 127.7 tok/s).

One stack measures ~1 TB/s of memory reads (991-997 GB/s), not its 1.6 TB/s on paper; the 27B's generation reads it at 32 %, its FFN GEMVs 56 % of a token. A sweep of the switches (hibagus, bench/xehpc_sweep.sh) found +7-10 % for each part; as this GPU's defaults since e905e4b they gave +6-12 % on the prompt and +5-7 % on generation (two passes each, #48). Long prompts fall behind the B70 (32K 0.75x, 262K 0.43x): its prompt attention takes 2.4x the B70's time at 4K.
