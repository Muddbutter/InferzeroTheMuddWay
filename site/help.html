Help out

inferzero is free and open source, and still far from what Intel's chips can do. Most of its speed came from people running it on hardware we don't have and posting what they saw. You don't need to write code to help.

Measure your hardware

The most useful thing most people can do: we can only tune for a GPU someone has measured.

  1. Install it and download a model with the launcher.
  2. Run the benchmark. Windows: run-tests.cmd quick in the inferzero folder (about an hour) writes one zip to the Desktop, with user names taken out of the paths. Linux: bench/website_bench.sh. One model by hand: bin\runz.exe <model.gguf> --bench-pp 4096 --n 128.
  3. Open an issue with the Hardware results template and attach the zip or paste the output.

Especially wanted

  • Arc A750, A580, A380 and B570 cards, and the laptop A-series (A370M, A770M).
  • Core Ultra laptops and mini PCs not on the results page yet: Meteor Lake, Lunar Lake, Arrow Lake H, Panther Lake.
  • Two or more Arc cards, above all on Windows and on Linux distributions not yet tried (several GPUs).

Report a problem

Something fails, crashes, gives wrong text, or is much slower than it should be: open a bug report. Say which GPU, system and release, which model, and how you started it. In the Windows launcher, Copy for an issue copies the log with user names taken out. Numbers that disagree with this website are welcome too: that is how most of the tuning was found.

Improve the code

The engine is C++ on Intel's Level Zero, with its GPU kernels in OpenCL C, for Windows and Linux. Places where help moves it most:

GPU kernels

The prompt and generation kernels on XMX and DP4a: each card's table on the results page shows how far from its peak it still is.

Several GPUs

Faster sums between cards on Windows, and a split by layers for slow PCIe links.

Linux and the web UI

Packages for Nix, Arch and Fedora, the Docker files, and the chat in the browser (one file, webui/index.html).

Start with the issues labelled good first issue and help wanted. CONTRIBUTING.md says how to build it and how every change is checked: answers compared with an exact reference, and the same results bit for bit where a change promises them.

Free and open source

inferzero costs nothing and never will. Its source code is public under the Apache 2.0 license: use it, change it, share it, at home or at work.
